# 开立单位银行结算账户申请书审核工具 — 规格说明

## 1. 项目概述

**项目名称**: BankAccountVerifier
**类型**: 桌面/轻量级 Web 应用（Python + Streamlit）
**核心功能**: 工作人员拍照上传营业执照、法人身份证、经办人身份证和开户申请书，小程序自动 OCR 识别并交叉核验填写内容，标记不一致项。
**目标用户**: 银行柜员、对公业务审核人员

---

## 2. 功能模块

### 2.1 图片上传（4张）
| 字段 | 说明 |
|------|------|
| 营业执照 | 企业营业执照（统一社会信用代码） |
| 法人身份证 | 法定代表人身份证正面 |
| 经办人身份证 | 经办人身份证正面 |
| 开户申请书 | 纸质申请书拍照件 |

### 2.2 OCR 识别
- 使用 EasyOCR（无需 GPU，中文识别效果好）
- 支持自动方向校正（预处理）
- 分别提取4张图片中的关键字段

### 2.3 关键字段提取

**营业执照提取字段：**
- 公司名称（企 业 名 称）
- 统一社会信用代码
- 法定代表人姓名
- 法人身份证号
- 注册地址

**法人身份证提取字段：**
- 姓名
- 公民身份号码
- 性别（辅助核验）
- 民族（辅助核验）

**经办人身份证提取字段：**
- 姓名
- 公民身份号码

**开户申请书提取字段：**
- 单位名称
- 统一社会信用代码
- 法定代表人姓名
- 法人证件号码
- 经办人姓名
- 经办人证件号码
- 注册地址
- 申请日期
- 加盖公章（图片）

### 2.4 交叉核验规则

| 核验项 | 比对对象 | 规则 |
|--------|----------|------|
| 公司名称 | 申请书 vs 营业执照 | 完全一致 |
| 统一社会信用代码 | 申请书 vs 营业执照 | 完全一致 |
| 法定代表人姓名 | 申请书 vs 营业执照 vs 法人身份证 | 三者一致 |
| 法人证件号码 | 申请书 vs 法人身份证 | 完全一致 |
| 经办人姓名 | 申请书 vs 经办人身份证 | 一致 |
| 经办人证件号码 | 申请书 vs 经办人身份证 | 完全一致 |
| 注册地址 | 申请书 vs 营业执照 | 省份+城市级别一致即可 |

### 2.5 结果展示
- 核验通过项：绿色标记
- 核验不通过项：红色标记 + 不一致原因说明
- 原始提取内容：供人工复核
- 支持导出核验报告（PDF）
